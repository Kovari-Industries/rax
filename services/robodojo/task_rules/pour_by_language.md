**Goal:** Pour each of the three bottles into its assigned bowl, in the order the instruction names them by colour.

**Success requires:**
- Each named pair is judged when its bottle is set back upright after pouring, and passes once it is poured.
- Poured means very little liquid is left in the bottle and nearly all spilled liquid is in that pair's bowl.
- All three pairs must pass.

**Fails the episode if at any step:** when an arm returns to its starting pose, a later pair has been poured before an earlier one.

**Partial credit (failed episodes):** the first pair poured, then the first two pairs poured, judged when an arm returns home.
