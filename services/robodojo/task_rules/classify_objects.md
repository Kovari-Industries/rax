**Goal:** Sort the objects so that each of the three bins holds all the objects of one category, and return both arms to their starting poses.

**Success requires, all at the same step:**
- Each bin holds every object of one category; any category may go in any bin.
- Every object rests inside its bin, none perched on a rim or held above it.
- Both arms are back near their starting poses.

**Partial credit (failed episodes):** one correct bin, then two correct bins (all of one category, no other category); each tier also needs open grippers.
